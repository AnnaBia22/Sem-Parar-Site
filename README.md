# Sem Parar Site

Um site modelo criado para o projeto **Sem Parar**. O objetivo é apresentar o projeto, suas iniciativas, informações gerais e detalhes sobre as atividades, promovendo visibilidade e acessibilidade para participantes e interessados.

---

## 🚀 Descrição

Este repositório contém o desenvolvimento do site oficial do projeto **Sem Parar**, dedicado às meninas que amam olimpíadas. O site busca:

- Apresentar o propósito do projeto  
- Divulgar detalhes sobre o mundo olímpico feminino  
- Facilitar o acesso às informações  
- Servir como base para futuras expansões e funcionalidades  

---

## 🛠️ Tecnologias Utilizadas

Até o momento, estamos trabalhando com:

- **Vue 3**
- **Vite**
- **Vue Router**
- **Javascript**

> Outras tecnologias poderão ser adicionadas conforme o desenvolvimento evoluir.
